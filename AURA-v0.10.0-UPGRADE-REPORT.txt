4. Enable 'Use private Qwen AI'.
5. Paste the SAME AURA_API_KEY value stored in your Modal 'aura-api-secret' into 'AURA cloud / private server token'. Never paste your Hugging Face token.
6. Keep 'Use private Gemma screen vision' enabled. The endpoint/model are already filled in.
7. Choose Whisper language Auto, Bengali, Hindi or English.
8. Save Settings, then use 'Test AURA voice'.
9. Test a normal Qwen question and then approve one screenshot for Gemma analysis.
